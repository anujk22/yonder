## Direction

Butter yellow, forest green, warm ivory, and restrained lilac. Soft vinyl surfaces, crisp silhouettes, tactile highlights. Manrope carries the mobile interface; Fraunces is reserved for the wordmark and selected editorial uses. Mobile home opens directly into the real map. Explore, Requests, Saved, and Help out form the four-tab structure.

## Motion

`BrandObject` animates each raster layer independently. Gentle six-point vertical drift and three-degree rotation create depth. Tapping Scout triggers a spring wobble and haptic feedback. Motion suspends on route blur and backgrounding; reduced-motion users get a static composition. `BrandScene` layers a map or answer object behind Scout, using different phases. Buttons compress on touch; tab indicators spring into place. Screen content uses layout-preserving entrances rather than web layout animations that can leave containers absolutely positioned.

The artwork never blocks search, location, attribution, save, or ask controls. The completion scene is explicitly a demo completion; real evidence is kept separate.
